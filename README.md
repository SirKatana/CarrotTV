What is CarrotTV?

CarrotTV is a Linux-based TV operating system designed for compatible TV hardware and single-board computers.

It is designed to provide a dedicated TV environment with an integrated application store, wireless networking, Bluetooth connectivity, and support for common input peripherals.

CarrotTV is intended to run on hardware including:

Raspberry Pi

Ugoos AM6B+

Features

Linux-based TV operating system

TV-focused user interface

Built-in App Store

Wi-Fi support

Bluetooth support

Bluetooth mouse support

Bluetooth keyboard support

USB peripheral support

Application installation and management

Support for compatible Raspberry Pi hardware

Support for Ugoos AM6B+

Designed for HDMI-connected displays

App Store

CarrotTV includes an App Store intended to provide applications for the TV operating system.

The App Store is part of the CarrotTV platform and is intended to make applications available directly through the operating system.

Connectivity

CarrotTV supports Wi-Fi networking on compatible hardware.

Bluetooth support allows compatible wireless peripherals to be connected, including Bluetooth mice and keyboards.

Other Bluetooth devices may be supported depending on the hardware and software support available on the target device.

Hardware
Raspberry Pi

CarrotTV targets compatible Raspberry Pi hardware and is designed to use the capabilities provided by the Raspberry Pi platform.

Hardware-specific functionality depends on the Raspberry Pi model being used.

Ugoos AM6B+

CarrotTV also targets the Ugoos AM6B+ Android TV box as supported hardware.

Hardware functionality depends on the platform support provided for the device.

Built on Linux

CarrotTV uses Linux as its underlying operating-system platform.

Linux provides the foundation for hardware, networking, Bluetooth, input devices, storage, and other system functionality used by CarrotTV.

Project Status

CarrotTV is a project under development.

Hardware compatibility, application support, system components, and other implementation details may change as development continues.

License
